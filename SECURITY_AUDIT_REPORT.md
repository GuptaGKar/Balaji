Eight new forward migrations were applied only locally; no applied migration file was edited. PostgreSQL 17 was used; fresh PostgreSQL 15.19 migration replay and all 416 assertions also PASS. Existing legacy migration names were preserved. No production credentials, data, infrastructure or API were used.

Private media is served by `web/src/app/api/order-media/route.ts` with the caller's cookies and Storage RLS, without the service-role client. Responses use private/no-store redirects and no-referrer; signed links expire after 60 seconds. A previously issued link can remain valid until expiry. Existing historical public URLs stop working after the private-bucket migration; deploy the web URL change and migration together under a separately approved rollout. Android proof View originally passed kind metadata as a URI; the repaired caller-authenticated signing path was tested on minified staff QA and the owner confirmed the viewer opened. Assigned-rider create-only upload was also tested through delivery. Full supported-client/media failure matrices remain open.

Local synthetic account/OTP/configuration material is stored in restricted /tmp files and excluded from reports. One local-stack CLI startup printed its default development DB connection line; the saved startup log was sanitized. No production secret was involved. Production data, pairing credentials and raw Auth responses were not collected in reports.

Dependency sources: [Next advisory](https://github.com/advisories/GHSA-2464-fhr4-w9xw), [Zod advisory](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5).
