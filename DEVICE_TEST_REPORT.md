## Device, isolation and preservation

Samsung SM-A346E, Android 16/API 36, 1080×2340, density 450. Wireless ADB was used throughout; repeated transport interruptions required owner reconnection/unlocking. No security setting was disabled. Serial, wireless endpoints and pairing credentials are omitted.

Separate customer `com.balaji.provision.audit` and staff `com.balaji.provision.staff.audit` apps, version 1.12 (13), coexist with the original 1.11 (12) apps. Only QA packages were installed/launched. No app was uninstalled or data cleared. Opt-in QA builds require an explicit loopback backend, use ADB reverse to local port 54321, restrict cleartext to loopback and remove Firebase initialization/service. Artifact identity/endpoint checks preceded installation. QA release builds use R8/resource shrinking, non-debuggable manifests and the existing QA debug signer; normal release uses its existing release signer. No signing key was created or replaced.

All automated writes used isolated local Supabase and synthetic fixtures. The owner entered profile/address values on the QA phone; those values are omitted from reports and masked by the UI helper. A new synthetic QA Device address was used for checkout; the original address was preserved. There was no production order, payment or inventory change.
